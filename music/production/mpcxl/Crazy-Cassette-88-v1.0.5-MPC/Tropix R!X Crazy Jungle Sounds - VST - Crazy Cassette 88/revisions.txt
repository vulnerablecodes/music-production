VERSION 1.0.5
========================================================================
Release prepared: 2026-11-14 01:38:58 PST (UTC-0800) | 2026-11-14 09:38:58 UTC
- User confirmed v1.0.4 reel images shift only on control changes, not continuously, on MPC XL.
- Investigated OpenMPC's moving-picture reporting path: host-cached values need audioMasterAutomate notifications; full UpdateDisplay calls rebuild screens.

- Added a bound UI counter below the version badge for on-device update-path diagnosis.
- Kept working audio processing and existing parameter IDs/order; removed the competing audio-thread phase publication only.
- Added a cached-host regression that advances all four speeds without user gestures and checks worker shutdown and callback thread.
- New cached-host tests, ASan/UBSan worker lifecycle check, UI binding audit, Speed audio checks, SDK ARM validation and native host 20/20 passed.
- LSan disabled in the sanitizer run due to tracing restrictions; new notification path still needs physical XL validation.
- This release addresses the missing repaint notification mechanism; it is not a claim of hardware-verified animation.

VERSION 1.0.4
========================================================================
Release prepared: 2026-11-14 01:13:02 PST (UTC-0800) | 2026-11-14 09:13:02 UTC
- User confirmed all four Speed audio settings work on MPC XL; reported all reels static in v1.0.3.
- Replaced displayed audio-phase telemetry strips with MPC-native animated Image sequences.
- Added equal-length 400-frame forward/reverse strips: 5/10/15/18 rotations per cycle for 1/4, 1/2, 3/4, 9/10.

- Reverse selects backward native animation. Displayed motion does not measure physical reel radius or audio latency.
- Retained Reel Phase at index 27 for saved-state compatibility, but removed it from visible reel bindings.
- Speed/audio algorithms unchanged; source matches v1.0.3 except plugin version metadata.
- Added ANIMATION FIX badge, native-animation frame/gate tests and updated preview rendering.
- Native host passed 20 checks; SDK validation and UI binding audit passed; all eight strips passed pixel-angle checks.
- Native timer behavior on physical MPC XL remains unverified until the user's next test.
