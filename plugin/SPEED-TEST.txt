CRAZY CASSETTE 88 v1.0.5 — SPEED TEST ON MPC XL

UPDATE
Save your MPC project. Replace the old complete plugin folder with the new one
inside VST2 Plugins. Keep only one copy on connected drives. Fully restart the MPC
so the old skin is not cached, then remove/reinsert the effect if necessary.
Look for v1.0.5 • LIVE REELS below the brand badge.

TEST
1. Play a sustained sample or loop on the track containing the insert.
2. Use Clean. Set Noise 0%, Mix 100%, Bypass OFF, Hold ON.
3. Tap the SPEED name to show the cyan cassette and four fraction buttons.
4. Press the LARGE RECTANGULAR PAD directly BELOW SPEED. Its LED should light.
   Selecting a mode name only edits its settings; it does not engage processing.
5. Tap each left-hand fraction button while audio continues:

   TOP BUTTON      1/4    quarter-speed ratio; pitch down two octaves
   SECOND BUTTON   1/2    half-speed ratio; pitch down one octave
   THIRD BUTTON    3/4    three-quarter-speed ratio
   BOTTOM BUTTON   9/10   nine-tenths-speed ratio

   The pressed fraction should light and the audible pitch should change.
   This live buffered varispeed processor creates granular/tape artifacts;
   it does not change the sequence BPM or rewrite the sample file.
6. Press the same large SPEED pad again: its LED goes black and the audio
   returns to the un-slowed path. Bypass also returns the original dry audio.

If the version badge or fractions are missing, the new skin has not loaded.
If the label is visible but a button does not respond, report which fraction,
whether the selected fraction lights, and whether the large SPEED LED is on.
Other effects can be checked individually after this Speed test succeeds.

REEL CHECK v1.0.5
1. Confirm the badge v1.0.5 • LIVE REELS (full restart after replacement).
2. Insert ON, Bypass OFF, Hold ON; select SPEED and engage its large lower pad.
3. With hands off the controls, watch the small UI nnn counter below the badge.
4. Both the counter and bright reel marker should advance continuously.
5. Select 1/4, 1/2, 3/4 and 9/10: movement should progressively accelerate.
6. Sequencer PLAY is not required. Turn SPEED off: animation should freeze.
7. If it still fails, report: does UI nnn change without touching anything?
   Are both reels frozen, or does only one move? Keep the v1.0.5 badge visible.

This new explicit-notification path passed a cached-host simulation and native
host checks. Physical XL display behavior is not verified by computer tests.
